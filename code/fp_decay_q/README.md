# 1D Fabry-Perot decay and Q fit

This deterministic calibration example propagates the stored energy of a
lossy 1D Fabry-Perot cavity one round trip at a time, fits the logarithmic
decay, and evaluates `Q = omega_0 tau_U`.

```powershell
C:\ProgramData\anaconda3\envs\AI_group\python.exe code/fp_decay_q/run_fp_decay_q.py
```

Dependencies: `numpy` and `matplotlib`.
