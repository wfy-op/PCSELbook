# PCSELbook project memory

- `main.tex`, `chapters/`, `frontmatter/`, `figures/`, and `refs.bib` are the canonical book sources.
- `build/pcselbook.pdf` is generated with XeLaTeX; do not edit it directly.
- `knowledge-site/` is the public, static, read-only knowledge site generated from the book.
- The website is tracked as regular files in this parent repository. Its former standalone Git history is preserved locally at `knowledge-site/outputs/git-history-before-parent-tracking-20260917`; do not publish that directory or the local `.openai` hosting configuration.
- Never hand-edit generated `knowledge-site/public/data/chapters/*.json` content.
- `cd knowledge-site; npm run sync:book` compiles a stale PDF and regenerates figures, chapter data, font subset, and KaTeX HTML.
- `npm run dev` performs an initial sync and watches book sources for further local synchronization.
- Optical tools use the registered project port `127.0.0.1:5175` via `npm run dev:training` without book synchronization. The unified Optical Lab in `app/optics/OpticalLab.tsx` has two separate pages: `/optics/tutorial/` (`app/training/`) and `/optics/designer/` (`app/design/`); `/optics/` opens the tutorial. A shared sticky header links both pages and returns to the book; BookSite has one lab entry. Old `/training/optical-bench/` and `/design/optical-bench/` remain compatible (including no trailing slash). `src/main.tsx` selects the lab page; `finalize_static_site.mjs` creates all five static shells and canonical metadata. All existing storage keys and engine behavior stay unchanged; ordinary page links restore persisted drafts/records, not in-memory undo histories. Site-wide book search does not index these app workspaces.
- Lab navigation gotcha: the book's global `html,body { overflow-x:hidden }` creates a body scroll ancestor and defeats sticky headers. `OpticalLab` adds/removes `ol-document` on html/body; lab CSS uses `overflow-x:clip; overflow-y:visible`, preserving the book's own reading-pane scrolling. Tutorial anchor offsets inherit `--ol-header-height` (76 px desktop, 116 px mobile). Practical record textareas have explicit aria-labels so restored values do not become part of their accessible names. Tracked browser acceptance is `scripts/qa_optical_lab.mjs` (`npm run qa:optics`); verify both draft types and course notes across page links, old routes, sticky anchors, and mobile overflow. Reports/screenshots belong under ignored `outputs/optical-lab-qa/` by default.

- Design v0.4 engine: `app/design/design-engine.ts` implements affine paraxial ABCD in air, finite lens/iris/target apertures, analytic geometric centroid best focus, EFL/BFL relative to ideal lens planes, Gaussian q propagation with 1/e² radius and effective-wavelength M² approximation, and actual bounded coordinate search of selected z positions. Full geometric source angle is mrad; Gaussian divergence is derived from wavelength/waist/M². No glass dispersion, thick lenses, aberrations, 3D spots, folded mirrors or physical clipping diffraction. Gaussian reference rays are not intensity weights. Envelope remains an untruncated reference when aperture checks fail; sample counts never imply power transmission.
- Design engineering file wraps validated `DesignProject` v2 in format `pcsel-optics-design`/formatVersion 1 with goals, positional variable IDs and constraints. Keys: `pcsel-optics-designer-draft-v2` and `pcsel-optics-designer-library-v2` (max 20 copies); v1 training scene migration is explicit in the project library. Manufacturer SKU is retained only after matching nominal f/OD against the local official catalog; clear-aperture basis stays separate. Optimization previews before apply, preserves source/specs/order, and can fix clipped starting designs even when honest RMS increases. Stale scan selections are cleared and parsed before applying. Self-contained HTML report embeds diagram, computed readouts and full escaped engineering JSON. Never call meridional y-RMS a 2D spot or PSF.

Browser acceptance script and screenshots: ignored `outputs/design-v4-qa.mjs` and `outputs/design-v4-*`. `npx vite build --outDir outputs/design-v4-build` plus `node scripts/finalize_static_site.mjs outputs/design-v4-build` validates local static routes without regenerating the book or deploying. - `npm run check` performs a synchronized production build, payload cleanup, tests, lint, and type checking.
- Design v0.5 adds true XY folded geometry in `app/design/folded-engine.ts` (48 ideal thin lenses/irises/mirrors/splitters/detectors). Plane normal angles are degrees; source full divergence is mrad. R/T are noncoherent power coefficients with explicit absorption and lossless UI coupling. Closest finite intersection chooses the next optic, outside-OD rays bypass it, clear-aperture annuli absorb. Separate captured/escaped/absorbed/unresolved budgets remain conservative even for loops/trace cutoffs; source weights are uniform discrete 1D sampling, not measured 3D beam power. Detector centroid/RMS/span are meridional line statistics. No glass thickness displacement, polarization, interference, aberration, dispersion or Gaussian q in this spatial engine.
- `OpticalDesigner.tsx` selects sequential/spatial modes (first visit spatial, key `pcsel-optics-workspace-mode-v1`) without discarding either history. `design-conversion.ts` copies geometric prescriptions and preserves the original; spatial undo restores its prior draft. Infinite targets become bounded detectors, catalog lenses become custom geometry, and Gaussian conversion is blocked. `FoldedScan.tsx` / `folded-scan.ts` compute actual 21-point X/Y/normal/focal sweeps constrained by chosen detector capture; stale candidates, zero reception and unresolved trace cannot win. It is a discrete single-variable comparison, not global optimization.
