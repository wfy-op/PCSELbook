# PCSELbook project memory

- `main.tex`, `chapters/`, `frontmatter/`, `figures/`, and `refs.bib` are the canonical book sources.
- `build/pcselbook.pdf` is generated with XeLaTeX; do not edit it directly.
- `knowledge-site/` is the public, static, read-only knowledge site generated from the book.
- The website is tracked as regular files in this parent repository. Its former standalone Git history is preserved locally at `knowledge-site/outputs/git-history-before-parent-tracking-20260917`; do not publish that directory or the local `.openai` hosting configuration.
- Never hand-edit generated `knowledge-site/public/data/chapters/*.json` content.
- `cd knowledge-site; npm run sync:book` compiles a stale PDF and regenerates figures, chapter data, font subset, and KaTeX HTML.
- `npm run dev` performs an initial sync and watches book sources for further local synchronization.
- `npm run check` performs a synchronized production build, payload cleanup, tests, lint, and type checking.
- Optical Lab routes are `/optics/tutorial/` (`app/training/`) and `/optics/designer/` (`app/design/`); `/optics/` opens the tutorial. Old training/design aliases remain valid with or without trailing slashes. `OpticalLab.tsx`, `src/main.tsx` and `finalize_static_site.mjs` own selection/static shells. Use `npm run dev:training` on registered `127.0.0.1:5175` without book synchronization. Before restoring a service, check the global port registry plus actual IPv4/IPv6 listeners; never stop another project. Current operation/model/architecture reference: [optics-workbench.md](knowledge-site/docs/optics-workbench.md).
- Design calculations belong in six pure modules under `knowledge-site/app/design/core/`; keep DOM, persistence and interaction outside them. Sequential `design-engine.ts` uses affine paraxial ABCD and Gaussian q/1/e² radius with effective-wavelength M²; Gaussian reference rays are not power weights, and a clipped Gaussian envelope remains an untruncated reference. Its y-RMS is meridional, never a 2D PSF. Spatial `folded-engine.ts` uses actual 3D ray/finite circular-plane intersections with normals/centers in XY and transverse Z; mirrors reflect in 3D but lenses remain local paraxial zero-thickness principal planes.
- Spatial old files retain original one-dimensional fan/extended sampling. Optional `source.beam` enables independent Gaussian/uniform elliptical position and angle quadrature in `beam-analysis.ts`, 64–4096 samples; Gaussian full widths are 1/e² (sigma=width/4). Cylindrical `focalSagittal:null` means zero power on that rolled axis. User OPD coefficients (µm) define an explicit, non-Zernike-normalized pupil polynomial, not manufacturer aberration. Detector `spot` contains actual hits, power/area bins, 2D centroid/RMS/covariance and principal axes. Preserve equal px/mm in both display axes. No diffraction/coherence/polarization, material dispersion, thick glass, high-NA fields or full device prescriptions; zero geometric width is never a zero physical focus or infinite irradiance.
- Spatial power must close as captured+escaped+absorbed+unresolved=input; outside-OD rays bypass optics, clear-aperture annuli absorb, and loops/trace limits retain unresolved power. Never turn sample counts into measured transmission. `core/folded-optimizer.ts` performs bounded cooperative local coordinate/pattern search with cancellation, selected x/y/normal/focal variables and capture/conservation constraints; `core/folded-scan.ts` keeps actual 21-point sweeps. Both use real current-source traces and reject missing reception, unresolved budgets and stale candidates. Preview before apply; no global-optimum or Zemax-equivalence claims.
- Source provenance: twelve Thorlabs lens f/OD/coating title records live in `public/training/thorlabs/`; default 90%-OD clear apertures are teaching assumptions, thickness/BFL stay null, engineering PDF/STEP/ZMX downloads returned 403. Three cylindrical current title records live in `public/training/cylindrical/`; 21 mm model aperture is the conservative bound of the official historical >21 mm specification. Six dry infinity objectives live in `public/training/objectives/` and `core/objective-model.ts`: f=tube f/M (Evident180, Mitutoyo200), estimated pupil=2NAf, WD is mechanical distance, and default25.4 mm blocking range is not housing geometry. Manual collection scripts never run on startup. Optical edits clear objective catalog attribution; imports never certify hardware.
- `FoldedDesigner.tsx` owns engineering state/undo/persistence; `FoldedWorkspace.tsx` owns canvas/inspector/detector displays; one `EquipmentLibrary` supplies expandable equipment categories and evidence. Keep storage keys/formats compatible: sequential `pcsel-optics-designer-{draft,library}-v2` / `pcsel-optics-design`, spatial `pcsel-folded-optics-{draft,library}-v1` / `pcsel-folded-optics`; libraries max20. Optional beam/cylinder/OPD fields survive validated JSON and HTML exports. `design-conversion.ts` copies geometry without destroying either history and blocks Gaussian conversion. `folded-labels.ts` derives D1/D2 by detector prescription order while preserving ID/name. Tutorial records and legacy16-element bench stay independent; the group pump photo confirms only the blue-fiber input, other topology/values are teaching assumptions.
