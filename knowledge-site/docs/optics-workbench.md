# 光学工作台：模型、结构与交接

入口：`/optics/designer/`。运行 `npm run dev:training` 使用登记端口 5175；不要用完整 `npm run dev` 触发教材同步。本应用是静态站点，计算在浏览器中完成，没有服务器数据库或账户写入 API。

## 操作

- 空间布局是主工作区。顶部“元件库”展开分类装备列表，选择器件后查看名义参数、模型假设和官方来源，再加入或拖入画布。右侧参数可收起；小屏使用折叠面板。
- 网格间隔和吸附间隔独立，以毫米输入。坐标、孔径和网格保持真实 XY 比例；元件图标有最小可见尺寸，光线显示线宽不会修改计算。适应元件、完整区域和缩放可切换观察范围。
- 椭圆高斯源可以设置两个横向直径、两轴发散全角和横截面旋转角。高斯参数是完整 1/e² 宽度；均匀源参数是椭圆边界。两个轴的名称标识输入，不强行交换轴值。
- 探测器 D1/D2/... 根据工程记录顺序编号，保留原 ID 和名称。二维光斑显示实际到达光线、功率直方图、积分剖面、质心和 RMS。u/v 的显示尺度相同，椭圆不会被拉成圆。
- “多变量局部优化”设置目标探测器、接收份额约束和变量上下界，计算候选后预览，再应用。可取消计算；工程或配置变化后不能应用旧候选。旧单参数扫描保留。
- 旧工程保留原一维模型；点击“启用二维椭圆光束”升级采样。工程 JSON、保存副本和导出 HTML 会保留二维源、柱透镜和自定义 OPD 参数。

## 实际模型

布局面为 XY，光学面法线在 XY 内，第二横向坐标 Z 在布局面外。光线使用三维单位方向和实际有限面交点；元件中心都在 Z=0。XY 计算区域终止逸出光线，没有隐藏的 Z 遮挡墙。镜面执行三维平面反射。透镜和物镜是空气中的理想零厚度主面，局部使用近轴斜率变化，不能把方向归一化理解为真实非近轴折射。

二维源使用四维 Halton 序列和反对称成对采样，独立采样位置与方向。`rayCount²` 控制样本预算，范围 64–4096。Gaussian 标准差为完整宽度的四分之一。所有样本承担离散相对功率；分光 R/T 是功率系数，没有相干相位。探测器接收、逸出、吸收、未完成四项加和须等于输入功率。

圆形孔径依据两个横向坐标裁剪；外径外光线绕过元件，通光孔径与外径之间吸收。柱透镜默认只在一个滚转后的横向轴有焦距，另一轴光学功率为零。滚转角可改变有功率轴方向。

自定义瞳面光程差为：

`W = S (ξ²+η²)² + C ξ(ξ²+η²) + A(ξ²−η²)`

ξ/η 是以有效孔径半径归一化的横坐标，S/C/A 单位 µm。实际方向变化来自光程差梯度，系数的符号约定见 `pupilAberrationSlope`。这些项不是标准化 Zernike 系数，也不是某款镜片的实测球差、彗差或像散。设为零恢复理想模型。

强度网格记录每格实际功率和功率/面积，单位 a.u. 与 a.u./mm²；不是相干光场、衍射 PSF 或实测辐照度。两轴积分剖面各自归一化，不能从剖面高度比较两个轴的总功率。几何零尺寸仅表示理想几何聚焦，显示用的有限网格不代表衍射极限或无限物理强度。

多变量优化使用有预算的局部坐标/模式搜索，支持 x/y、法线角和焦距，最多八个变量。完整追迹、目标接收份额、未完成功率和守恒约束共同筛选候选；不能通过完全截光来假装获得更小光斑。此算法没有全局最优保证。顺序模式仍使用其独立 ABCD/Gaussian 模型。

## 器件依据与范围

装备库包含原十二款球面/消色差透镜、六款无限远物镜、三个柱透镜型号及反射分光参考器件。球面名义 f/外径/镀膜来自 `public/training/thorlabs/`，其 90% 外径孔径仍是模型假设。柱透镜 LJ1695RM-A、LJ1567RM-A、LJ1653RM-B 的名义焦距分别为 50、100、200 mm，直径 25.4 mm，来源记录在 `public/training/cylindrical/`。模型孔径 21 mm 使用[官方历史目录](https://www.thorlabs.com/catalogpages/V21/764.PDF)的保守下界。当前官方 ZMX 下载返回 403，未导入真实镜片处方，也未绕过访问控制。

物镜等效焦距为配套筒镜焦距/倍率；WD 是机械工作距离。后瞳估计 2 NA f 和默认遮挡外径不是完整物镜几何。高 NA 全孔径、盖玻片和真实物镜内部处方没有计算。

专业分析参考：[Ansys 几何扩展源分析](https://optics.ansys.com/hc/en-us/articles/42661975992851-How-to-generate-cross-section-and-moment-data-for-an-extended-source-using-Geometric-Image-Analysis)介绍了效率、二维质心和径向 RMS；[Ansys 激光传播说明](https://optics.ansys.com/hc/en-us/articles/42661513633683-How-to-model-laser-beam-propagation-in-OpticStudio-Part-1-Gaussian-beam-theory-and-ray-based-approach)区分几何光斑与衍射尺度。本实现落实了这些可检查读数，但没有宣称等同 Zemax/OpticStudio：真实曲率/厚度/玻璃色散、完整三维倾斜偏心处方、衍射、偏振、容差与全局优化仍未实现。

## 文件结构与数据流

| 位置 | 职责 |
|---|---|
| `app/design/core/` | 六个无 DOM/存储依赖的计算模块：顺序、空间、二维采样、优化、扫描、物镜模型 |
| `FoldedDesigner.tsx` | 工程状态、撤销、持久化、器件插入、导入与组件组合 |
| `FoldedWorkspace.tsx` | 画布、紧凑参数设置、实际探测器图和积分剖面 |
| `EquipmentLibrary` / `equipment-catalog` | 一套分类装备选择与来源说明 |
| `FoldedOptimizer` / `FoldedScan` | 计算任务的交互和候选应用 |
| `design-projects` / `*-export` / `design-conversion` | 版本校验、存储、下载、跨模型复制 |
| `public/training/` | 已核验的官方规格原始记录，供用户下载 |
| `scripts/qa_*` / `tests/` | 浏览器验收与解析/数值/守恒基准 |
| `outputs/optics-workbench/` | 统一本地验收结果、截图、报告与清理清单，禁止发布 |

输入 → 导入校验/工程状态 → 纯计算核心 → 实际光线/预算/探测器读数 → UI。优化候选调用同一核心，应用前再次核对签名。未来可把 `core` 调用移入 Web Worker 或云任务；不为尚未存在的服务增加空目录和依赖。

## 验收与云端准备

```text
npm run test
npm run typecheck
npm run lint
npm run build:optics
npm run qa:workbench
```

`build:optics` 使用已有教材静态数据构建、生成独立页面并清理/审计 `dist/client`，不触发书稿生成，不上传云端。真正发布仍需用户明确授权；只上传审计通过的 `dist/client`。`.git`、`.openai`、本地输出和临时目录均禁止进入部署负载。

浏览器脚本使用一次性存储上下文，默认本地 5175。`PCSEL_PLAYWRIGHT_MODULE` 可指定已安装 Playwright 模块的 file URL；`PCSEL_OPTICS_BROWSER_CHANNEL` 默认 msedge。当前验收使用桌面和手机批量截图，修复后最多一次确认，不反复截图微调。

测试覆盖原顺序/空间工程、解析/来源、两轴自由传播、反射和柱透镜互易、圆孔径功率守恒、OPD 梯度、二维扫描和多变量实际改进。采样误差和性能必须引用实际基准，不把一个简单场景的耗时当成普遍保证。清理清单中的 61 项历史产物已送入回收站；8 个旧构建目录因 Windows 回收接口失败合并保留在一个 outputs/retired-legacy-builds 目录，移动前后文件数、字节数与 SHA256 清单一致。原对话诊断证据、原 Git 历史、运行日志和教材资料均保留。
